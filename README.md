# katcinskiy.github.io

Personal website of Alexander Yukhimchuk, served at https://katcinskiy.github.io by GitHub Pages from the `gh-pages` branch.

Plain HTML/CSS, no build step (`.nojekyll`). Edit `index.html`; styles are in `assets/style.css`.
Text still to be filled in is marked with `class="placeholder"` (highlighted in yellow).

- `go-and-guess/` – page for the Go&Guess app
- `app-ads.txt` – AdMob verification for the app, must stay at the site root
